# 愤怒的坤坤（angry-kunkun）

一个用原生 HTML5 Canvas + 原生 JavaScript 写的弹弓弹射小游戏，零依赖、单文件即可运行。

## 玩法
- 按住左侧弹弓向后拖拽，松手发射橙色篮球。
- 撞掉全部紫金 24 号目标即过关，共 2 关，每关 3 发弹药。
- 支持鼠标与触屏。

## 运行
直接用浏览器打开 `index.html` 即可，无需安装任何依赖或构建工具。

## 技术说明
- 单文件，内联 CSS / JS，无框架、无第三方库。
- 简单抛体物理：重力、圆-矩形碰撞、圆-圆碰撞、地面摩擦与静止判定。
- 纯个人学习练习项目；角色均为抽象符号，未使用任何真实人物肖像或商业素材。
